Nested Component Definitions (react-hooks/static-components) Files: components/AddDataModal.tsx How to fix: You defined a component called <TabButton> inside the body of the AddDataModal component. Because it's nested, React completely recreates the <TabButton> function from scratch on every render, which hurts performance and destroys state. Move TabButton outside of AddDataModal, or just call it as a normal helper function like {renderTabButton(...)} instead of <TabButton />.

2. Synchronous State Updates in Effects (react-hooks/set-state-in-effect) Files: AddDataModal.tsx, Dashboard.tsx, EditMappoolModal.tsx, EditRosterModal.tsx, ManageTournamentModal.tsx, ManualScoreEntry.tsx, ThemeSelect.tsx How to fix: The React team strongly discourages calling setState directly inside a useEffect (like when checking if a modal isOpen) because it causes cascading double-renders. Instead of using useEffect to reset your state, a better approach is to reset the state inside the onClick event handler that originally opened the modal. Alternatively, you can pass a key prop to the modal when rendering it (e.g. <AddDataModal key={isOpen ? 'open' : 'closed'} />) which tells React to automatically wipe and recreate the component's state for you.

3. Using <img> instead of <Image /> (@next/next/no-img-element) Files: app/profile/page.tsx, components/UserDropdown.tsx, components/PlayerScoreHistoryModal.tsx How to fix: Next.js wants you to use its optimized <Image> component exported from next/image. Because you already have the a.ppy.sh domain properly configured in the remotePatterns block of your next.config.js, you can safely swap out these <img> tags with <Image src={...} alt="..." width={...} height={...} />. If you prefer to keep the standard <img> tags, just add {/_ eslint-disable-next-line @next/next/no-img-element _/} on the line above them.

4. Unescaped Entities (react/no-unescaped-entities) Files: app/page.tsx, app/profile/page.tsx, components/TeamHubClient.tsx, components/TeamIntel.tsx How to fix: You have raw single quotes (') in your JSX text. React expects you to escape them. Simply change the ' characters to &apos; or evaluate them in JSX like {"'"}.

5. Conditional Hooks (react-hooks/rules-of-hooks) Files: components/AnalyticsPanel.tsx How to fix: You placed a useMemo hook inside an if block, or after an early return. React requires hooks to be called in the exact same order on every render. Move the useMemo call to the top level of your component, before any conditional logic.

6. Missing Dependencies (react-hooks/exhaustive-deps) Files: components/TeamIntel.tsx, components/PlayerScoreHistoryModal.tsx How to fix: Your useEffect or useMemo hooks rely on variables from the component body that aren't listed in their dependency array (like handleClose, filteredScores, or activeTournament?.players). Add them to the array (making sure to wrap any functions/objects in useCallback or useMemo to prevent infinite loops).
